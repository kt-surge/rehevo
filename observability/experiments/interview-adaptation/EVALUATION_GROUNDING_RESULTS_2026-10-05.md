## 新发现：重试和工具调用成本

旧诊断 2 次 invoker 操作暴露 5 个 Chat SDK 操作 / **35,754 Token**；候选 1 次 invoker 操作暴露 8 个 Chat SDK 操作 / **54,000 Token**；合计已暴露 **89,754 Token**。内部调用数不能等同于 HTTP 请求数。两边无 Embedding/ASR/TTS。成功返回的模型累计 Token 及内部格式失败保留；不能把中央尝试次数当作供应商调用次数。

`validateSchema()` 启用 SDK 自校验重试，外层 StructuredOutputInvoker 也重试；工具继续调用也会增加 SDK 操作。下一步先固定中央结构重试预算，同时保留 Schema 失败检测，修正诊断使用真实有界执行器，再复验公开输入；暂不盲目换模型或增加样本。[Spring AI 官方说明](https://docs.spring.io/spring-ai/reference/api/structured-output/validation.html)
