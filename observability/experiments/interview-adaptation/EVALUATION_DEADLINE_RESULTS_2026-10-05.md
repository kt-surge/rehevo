# 评估超时取消：实现与实测结果

## 保留的实现

UnifiedEvaluationService 的批次、失败题恢复、汇总共用现有有界执行器和整份报告截止时间。使用可取消 FutureTask，取消时中断实际线程，并通过任务范围的 AiCallCancellation 调用自己的 HTTP Call.cancel()。响应头前和正文阻塞均覆盖；不取消共享客户端的其他请求。任务结束清理绑定与回调，没有新增线程池、依赖或内部请求头。

StructuredOutputInvoker 每次结构尝试前、结果返回后检查中断及调用方预算，过期后不开始下一次尝试、不采用迟到结果。保留同步请求、严格 JSON/Schema 与中央两次重试。三个评分入口使用已有 NONE 客户端；模型设置、语音实验标志、正文选择默认值不变。

真实 Registry + Spring AI 2.0.1 / OpenAI Java core 4.49.0 对 loopback HTTP，无外部模型调用。HTTP fixture 在响应头前或响应头后持续静默，报告预算 2 秒，取消后观察窗 1.8 秒；最终两例均看到对端 EOF，执行器能结束。不从两个固定场景估计生产时延、可靠性或供应商停止计费。

六个截止边界还包含底层清除中断后停止重试、汇总与失败题恢复超时。三个范围测试覆盖嵌套任务、取消后晚注册请求和任务结束清理。正常无绑定的共享客户端仍按既有路径请求。
