# 出题分类契约修复

## 实际缺陷与方案审查

本轮真实 Flash 对照旧/新各三题，type 均返回 CORE/CORE/ALWAYS_ONE；这些是分布优先级，不是 Skill 分类 key。InterviewSkillService.buildAllocationDescription 仅注入显示名、数量与优先级，既未给 key，也没有服务端合法类型检查。错误类型会进入历史题目/分类分布，与模型语义质量分开处理。

在分配表增加独立 key 列并明确优先级不是 type；简历题补同一 Skill 的允许 key/显示名清单，按既有数据边界净化与包裹。服务端优先接受本次 Skill 的精确 key（仅 trim/忽略大小写）；模型将优先级误填为 type 时，只能用同条题目已有的分类 key/显示名精确恢复。均未知则 BusinessException 拒绝，不猜一个分类，也不加模型重试。追问继承主问题合法 type。

不按题干语义或训练名称模糊归类，不修改分配算法、模型、训练目标 ID、问题数量、中央 Schema/尝试上限或原质量门。只有无分类的通用降级路径仍返回 GENERAL。合法类型仍不证明问题/Rubric 内容正确。
