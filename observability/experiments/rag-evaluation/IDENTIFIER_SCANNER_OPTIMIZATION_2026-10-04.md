# 技术标识正文扫描优化

## 改动与保留条件

旧实现对每个标识及所有候选执行带两段有界通配的正则，再构造两个匹配列表。新实现保留同一标题和签名语义，将窗口搜索拆成有界扫描，在发现第一个正文候选后停止后续候选扫描。

保留锚点提取、大小写、ASCII 提及边界、Java 正则签名前的词边界、120 与 180 码点窗口、默认正则空白、连续同名标题、首个正文/首个提及的优先级、重复 ID 处理、预留上限、完整块预算和原候选顺序。没有新增检索、读取 Gold、截断原文或扩大上下文。`HYBRID_IDENTIFIER` 仍需显式选择，默认仍为 `HYBRID`。

旧源码先冻结到 [baseline](runs/identifier-scan-20261004-r1/baseline)，原始 SHA-256 `0ea4bc8da09b117b300a7d9014acb47f1e21422cdf151b1db0bd569d64a1f25d`。实验 oracle 仅改类名以与新实现同进程编译，原始副本保留。

## 语义与回归门

- 原 92 份实际问题/候选：真实 Token 估算下比较 top8/6000，并用其他 topK/预算比较选择。
- 4,456 份独立边界输入：窗口距离 0–325、连续标题、CRLF、非 BMP 字符、默认和非默认空白、多个锚点及重复 ID；随机种子 61004。
- 总计 13,828 次差分均通过；比较完整 Document 列表、锚点、预留条目、正文标记和 Token 估算。
- 69 套件、322 项后端完整 fresh 回归通过，无失败/错误/跳过。

证据：[parity.json](runs/identifier-scan-20261004-r1/parity-cpu-r1/parity.json)、[原始回归](runs/identifier-scan-20261004-r1/regression-r1)。这是有限输入的等价验证，不是对任意字符串的数学证明；没有增加新质量样本或独立人工审核。

## 评审与接续

由执行 Agent 自审，没有独立人工或第二位 Agent 评审。决定：保留语义等价的扫描优化，保留 `HYBRID_IDENTIFIER` 作为显式实验策略，默认 `HYBRID` 不切换。本会话成本门可以让生成质量实验继续，但不替代固定上下文的忠实度、完整性、引用/拒答、独立时间窗及完整产品验收。

既有开发和新资料测试的必要证据收益没有因扫描优化改变，亦没有新增质量样本；不能把 216 次重复请求写成 216 题或重算更高准确率。后续如果改变标识规则、候选选择或 Prompt，应冻结新的开发方案与未用于调参的最终测试材料。
